# 🐛 Flaw — Bug Tracker API

A REST API for tracking bugs, built as a 1-week MVP sprint.

## Tech Stack

- Java 17 + Spring Boot 3
- Spring Security 6 (JWT)
- PostgreSQL on Neon
- Spring Data JPA

## Roles

| Role | Can Do |
|------|--------|
| `QA` | Create teams, add members, report bugs, assign to developers |
| `DEVELOPER` | Self-assign bugs, update status, comment |

## API Docs

Run the app and visit `/swagger-ui/index.html` for the full interactive API documentation.
